営業プレイブック

結論：自分自身の業務委託案件を探し、直接提案することは可能です。ただし、求人・求職の申込みを受けて他人の雇用成立を有料であっせんする事業や、雇用した人を顧客の指揮命令下で働かせる派遣事業は、それぞれ許可制度の対象です。契約名ではなく実態も確認します。
1. 売る内容を1枚にする
  • 対象：誰の、どんな課題を解くか
  • 提供：担当範囲・成果物・稼働開始日・週の稼働量
  • 根拠：スキルシート、匿名化した実績、GitHub・制作物
  • 条件：希望単価、下限、勤務地・リモート、契約形態
2. 見込み案件を作る
  1. 元同僚・取引先への紹介依頼
  2. 企業の採用・問い合わせ窓口へ直接提案
  3. フリーランスエージェント・案件サイト
  4. 勉強会・コミュニティの関係構築

検索結果の「営業候補に追加」から、この画面へ取り込めます。まずは週5件接触・3件フォローを目安に調整してください。

3. 初回連絡テンプレート
ご担当者様\n\n突然のご連絡失礼します。［技術・領域］を中心に、［具体的な成果・経験］を担当してきたフリーランスエンジニアです。\n貴社の［案件・事業］を拝見し、［解決できそうな課題］でお役に立てると考えご連絡しました。\n\n稼働：［開始日／週○日］\n働き方：［リモート／出社可能地域］\n希望条件：［単価帯・契約形態］\n実績資料：［URL］\n\n15〜30分ほど、現在の課題と期待役割を伺えますでしょうか。
4. 商談で確認する
  • 事業目標と、今回募集する理由
  • 任せる業務・成果物・完了条件
  • 体制、技術、意思決定者、日々の指示者
  • 契約階層（エンド／元請／再委託）と再委託可否
  • 単価、精算幅、支払期日、経費、開始・終了条件
  • 面談後の次の一手と回答期限
5. 提案とフォロー

面談当日中を目安に「理解した課題／自分ができること／最初の30日／前提条件」を短く送ります。回答期限を合意し、期限後は1回フォロー。合わない案件は理由を記録して終了します。

契約前の法務境界
  • 業務内容、報酬額、支払期日などは書面または電磁的方法で明示してもらう。
  • 発注者が日々の仕事の進め方を直接指揮する実態なら、準委任・請負という契約名だけで判断しない。
  • 他人の就職を報酬付きであっせんする事業、雇用した人の派遣は、自分の案件営業とは分ける。

これは一般的な整理で、個別案件の法律相談ではありません。
