# Skill Gap Planner

求人票を貼り付けると、AIが要求スキルを分解し、未習得・学習中・習得済みのボードで管理するローカルGUIです。
未習得スキルごとにAIと相談し、教材・制作課題・完了条件を含む学習計画を更新できます。

## 求人検索

画面上部の「求人を検索」から、技術・職種キーワード、地域・働き方、契約形態を指定して現在の求人候補を検索できます。
初期条件は `TypeScript` と「東京・関西・フルリモート」です。結果の「分析候補にする」を押すと既存の求人分析画面へ入り、元求人へのリンクも残ります。

求人検索にはOpenAI Responses APIのWeb Searchを使います。通常の分析モデルは `OPENAI_MODEL`、検索モデルは `OPENAI_SEARCH_MODEL` で変更できます。
検索結果は掲載終了や条件変更の可能性があるため、応募前に必ず元ページで確認してください。

## SES・フリーランス営業

画面上部の「営業管理」に、自分自身の業務委託案件を獲得するための手順をまとめています。売り方の整理、見込み案件の作り方、初回連絡テンプレート、商談項目、提案・フォロー、契約前の確認まで参照できます。

案件パイプラインでは、会社・案件・接点・単価・契約形態・次のアクション・期限を保存し、候補から受注／見送りまで状態を管理できます。各候補には業務範囲、報酬、支払期日、指揮命令、契約階層、解約、知財、賠償、経費のチェック欄があります。求人検索結果と取り込み済み求人の「営業候補に追加」から登録することもできます。

営業管理機能はAIキーなしでも使えます。法務欄は一般的な確認事項であり、個別契約の法律相談ではありません。

## 起動

```sh
export OPENAI_API_KEY="..."
python3 tools/skill-gap-planner/server.py
```

ブラウザで <http://127.0.0.1:8766> を開きます。終了は `Ctrl+C` です。
モデルを変える場合は `OPENAI_MODEL`、検索モデルを変える場合は `OPENAI_SEARCH_MODEL`、ポートを変える場合は `SKILL_GAP_PORT` を指定します。

```sh
OPENAI_MODEL=gpt-5-mini SKILL_GAP_PORT=9001 python3 tools/skill-gap-planner/server.py
```

## データとプライバシー

- 求人原文・進捗・AIとの会話・営業候補はルートの `skill-gap-data.json` に保存します。このファイルは `.gitignore` 済みです。
- `profile.json` があれば、登録済みの技術名・習熟度・経験年数をAIの照合材料に使います。プロフィール自体は変更しません。
- APIキーは環境変数（優先）またはmacOSキーチェーンから読みます。求人データ、ブラウザ、LaunchAgentのplistには保存しません。
- 「求人を検索」「AIで分析」「AIに相談」を実行したときは、検索条件・求人文・対象スキル・相談文がOpenAI APIへ送信されます。機密情報や個人情報は入力しないでください。
- APIリクエストには `store: false` を指定し、Responses APIの応答保存を無効にしています。
- 複数タブで同時編集した場合、古いタブからの保存は拒否して最新状態を再読み込みします。
- ローカル専用の `127.0.0.1` で待ち受けます。外部公開は想定していません。

## AIなしで使う

APIキーが未設定でも、手動追加・状態移動・編集・保存は使えます。AI機能だけがエラーになります。

## Macログイン中に常駐させる

一度だけ次を実行します。

```sh
python3 tools/skill-gap-planner/install_launchagent.py
```

以後はMacへのログイン時に自動起動し、[http://127.0.0.1:8766](http://127.0.0.1:8766) を開くだけで使えます。
ターミナルを閉じても停止せず、異常終了時は自動再起動します。

- 設定：`~/Library/LaunchAgents/local.skill-gap-planner.plist`
- ログ：`~/Library/Logs/skill-gap-planner.log`
- 停止：`launchctl bootout "gui/$(id -u)/local.skill-gap-planner"`
- 再登録：上記のインストールコマンドをもう一度実行

LaunchAgentにはAPIキーを保存しません。画面上部の「AIキー未設定」を押して一度登録すると、macOSキーチェーンへ保存され、以後は常駐起動でもAI分析と求人検索を利用できます。
環境変数 `OPENAI_API_KEY` が設定されている場合は、キーチェーンより環境変数を優先します。
